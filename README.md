# Amyal – Saudi Arabia Travel and Events Website

## Problem
Exploring Saudi Arabia can be challenging for both local residents and international visitors who are unfamiliar with the country's cities, attractions, and activities. Finding information about events, discovering places to visit, and arranging participation in activities can require searching across multiple sources, making travel planning less convenient.

## Solution
Amyal is a web-based platform designed to help users discover events and activities across Saudi Arabia. It provides information about selected events, including their locations and descriptions, and allows users to proceed to a booking page to submit their details and reserve tickets. The website also includes About Us and Contact Us pages, offering users additional information about the platform and a way to get in touch.

## Methods and Technologies
- **Frontend:** HTML, CSS, and JavaScript were used to build the website's pages, layouts, styling, and interactive features.
- **Backend:** Node.js and Express.js were used to create the server and handle requests submitted through the website.
- **Database:** MySQL was used to store reservation and contact form submissions, with the `mysql2` package connecting the application to the database.
- **Event Booking System:** Users can view event details, enter their booking information, select the number of tickets, and submit reservations through a form connected to the backend.
- **Dynamic Content:** JavaScript and URL query parameters were used to pass event information to the booking page, allowing it to display the selected event's details.
- **Form Processing:** Express.js routes handle booking and contact form submissions and interact with the database to store the submitted information.
- **User Feedback:** SweetAlert2 was used to display booking confirmation messages and provide feedback to users after submitting their reservations.
